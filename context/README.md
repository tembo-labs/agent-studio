# Context

This folder contains product context and planning documents for Tembo Agent Studio.

## Structure

- `planning/`: rollout plans, user stories, and consolidated project decisions.
- `strategy/`: feature-level context and strategic capability definitions.
- `demos/`: demo scripts by milestone.

## Index

- `planning/USER_STORIES.md`: Connextra user stories for phased rollout `0.1` to `0.4`.
- `planning/PROJECT_NOTES_FULL_CONTEXT.md`: Consolidated planning notes and historical product decisions.
- `strategy/FEATURE_DETAILS.md`: Detailed product behavior and implementation scope context.
- `strategy/MYCELIUM.md`: Tembo Mycelium model, operating modes, and governance.
- `demos/DEMO_SCRIPT_01.md`: Demo script for Phase `0.1` foundation milestone.

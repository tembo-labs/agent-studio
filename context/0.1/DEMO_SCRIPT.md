# v0.1 Demo Script

Target duration: 12-15 minutes.

## Flow
1. Deploy TAS.
2. Sign in via better-auth.
3. Create workspace and connect repo.
4. Add Tembo API key.
5. Create/import first agent.
6. Run manually and show logs.

## Success Criteria
- Successful sign-in via org IdP.
- Repo and API key saved.
- One successful agent run with logs.

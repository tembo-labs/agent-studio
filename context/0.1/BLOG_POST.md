# Blog Post: Introducing Tembo Agent Studio v0.1

Tembo Agent Studio v0.1 is the foundation milestone. This release focuses on getting teams deployed, authenticated, connected to Git + Tembo, and running a first agent safely.

If your organization wants a self-hosted agent control plane with strong future governance, v0.1 is the starting point.

What you get now:
- Docker-first self-hosting
- `better-auth` identity integration
- Workspace setup with repo + Tembo API key
- First agent import/create and run

What comes next:
- v0.2: chat authoring and PR policy controls
- v0.3: governance and audit depth
- v0.4: adaptive intelligence, variants, and Mycelium

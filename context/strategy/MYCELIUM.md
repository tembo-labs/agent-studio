# Tembo Mycelium

Tembo Mycelium is an optional shared learning network for TAS instances.

## What It Is

Admins can connect a TAS instance to Tembo Mycelium to share and reuse agent intelligence across organizations.

## Core Capabilities

- Auto-share successful agent patterns, templates, learned behaviors, and variants.
- Discover and import high-quality agents or variants from other organizations.
- Preserve attribution and provenance for imported/shared artifacts.
- Apply granular privacy controls at the instance and artifact level.

## Operating Modes

- Private mode: run fully isolated (air-gapped / no sharing).
- Networked mode: participate in collective intelligence through controlled sharing.

## Governance Expectations

- Sharing should be policy-controlled by admins.
- Imports should remain auditable and traceable to source.
- Privacy and compliance settings should be explicit and reviewable.

## Phase Mapping

Mycelium is introduced in **Phase `0.4`** as an optional capability, not a prerequisite for foundation rollout.

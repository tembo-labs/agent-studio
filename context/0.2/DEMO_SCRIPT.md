# v0.2 Demo Script

Target duration: 18-22 minutes.

## Flow
1. Complete v0.1 setup path quickly.
2. Chat: create a new agent request.
3. Show generated PR.
4. Apply review-required policy and merge.
5. Chat: request behavior change.
6. Show second PR and YOLO policy toggle.
7. Add schedule and trigger a run.
8. Show pause/resume checkpoint.

## Success Criteria
- Two PR-driven changes completed.
- Policy mode switch demonstrated.
- Scheduled and manual operations both shown.

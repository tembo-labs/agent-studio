# v0.4 User Stories

Connextra format:
**As a** `[role]`, **I want** `[capability]`, **so that** `[benefit]`.

- As an end user, I want corrections on agent output to generate targeted code-change PRs, so that the system improves from real usage feedback.
- As an operator, I want a one-click Modify + Rerun workflow, so that I can quickly test behavior changes after feedback.
- As a workspace admin, I want divergence detection across conflicting feedback, so that user groups can evolve separate variants safely.
- As a team lead, I want lineage visualization of parent and variant agents, so that we can understand evolution history before merging or splitting.
- As an enterprise admin, I want optional Mycelium sharing controls, so that we can choose private or networked learning modes.
- As a platform architect, I want a future MCP integration option for Tembo, so that TAS can support standardized tool connectivity when public MCP is available.

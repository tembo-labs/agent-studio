# Tembo Agent Studio v0.4 README

## Press Release (PRFAQ Style)

Today we are launching **Tembo Agent Studio v0.4**, the adaptive intelligence release. TAS now closes the loop between human feedback and agent evolution with correction-to-code PRs, Modify + Rerun, and variant lineage management.

v0.4 also introduces optional **Tembo Mycelium** connectivity for shared learning across TAS instances, while preserving private island operation.

## FAQ

### What is new vs v0.3?
- Correction-to-code learning loop
- One-click Modify + Rerun
- Divergence detection and variant creation
- Lineage visibility and reconciliation/speciation controls
- Optional Mycelium shared-learning network

### Does this force network sharing?
No. Mycelium remains optional and policy-controlled.

## Strategy, Features, Technical Details

### Strategy
Turn usage feedback into governed adaptation, not uncontrolled drift.

### Features
- Targeted PRs from observed corrections
- Divergence-aware variant lifecycle
- Lineage-first governance tools
- Optional network effects through Mycelium

### Technical Details
- LLM-assisted correction analysis through Tembo coding flows
- Variant metadata and lineage graph state
- Mycelium import/share controls with attribution and privacy

# v0.4 Demo Script

Target duration: 35-45 minutes.

## Flow
1. Recap v0.3 governance quickly.
2. Run agent and capture a human correction.
3. Show correction-to-code PR generation.
4. Merge and trigger Modify + Rerun.
5. Demonstrate conflicting feedback creating a diverging variant.
6. Show lineage view and admin reconcile/speciate options.
7. Show optional Mycelium policy configuration (island vs networked).

## Success Criteria
- Correction produced targeted source update.
- Modify + Rerun completed with updated behavior.
- Variant lifecycle and lineage governance demonstrated.
- Mycelium shown as optional, policy-controlled capability.

# Blog Post: Tembo Agent Studio v0.3 Adds Governance Depth

v0.3 turns TAS into a mature control plane for teams running agents in real workflows.

New capabilities include immutable change history, rich human-in-the-loop forms, and dashboard visibility for operations and support teams.

This release focuses on confidence at scale:
- Clear accountability
- Strong review surfaces
- Better operational response when runs fail or require intervention

## What is Tembo Agent Studio?

Tembo Agent Studio (TAS) is a self-hosted control plane for AI agents. Agent
definitions live as files in a Git repository you own, every change flows
through a pull request, and runs, audit logs, and identity stay inside your
environment. Agents inherit the discipline you already use for production code —
version control, code review, audit logs, identity, and RBAC.

<CardGrid stagger>
  <Card title="Author from chat" icon="pencil">
    Describe a change in plain language; TAS opens a pull request against your
    repo. Humans and AI authors produce the same artifact — a reviewable diff.
  </Card>
  <Card title="Run & automate" icon="rocket">
    Run agents on demand, on a schedule, or from external events, and inspect
    every run's output, token cost, and the tools it called.
  </Card>
  <Card title="Connect your stack" icon="puzzle">
    Authorize Slack, Gmail, Sheets, Notion, Attio, and ~1,000 more services, and
    reference them from an agent's `connections:`.
  </Card>
  <Card title="Govern everything" icon="approve-check">
    An append-only audit timeline, role-based access, and a per-agent health
    dashboard keep adaptation explainable.
  </Card>
</CardGrid>
